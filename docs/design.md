# 个人网站 Design

## 页面区块与浏览顺序

1. 个人信息：姓名、学校学院、专业、成绩、电话、邮箱、GitHub 和简历下载。
2. 教育背景：课程、成绩、英文授课情况和奖学金经历。
3. 实习经历：东亚银行 AI 审计产品经历。
4. 项目经历：薪火集、广货行天下。
5. 比赛经历：中国国际大学生创新大赛经历、证书和项目材料截图。
6. 科研经历：合成虚拟人用户项目与气泡图。
7. 技能荣誉：编程、工具、英语和奖项。
8. 附件下载：简历、两个奖状、项目材料节选和奖学金证明占位。

## 颜色、字体与整体风格

- 风格：明亮、正式、适合 HR 阅读的网页版简历，不使用黑色暗色背景。
- 主色：青绿色，用于按钮、强调信息和关键数字。
- 辅助色：陶土色和金色，用于标题辅助信息和荣誉感。
- 背景：米白、浅绿和白色，保持阅读轻盈。
- 字体：系统中文无衬线字体，优先保证 Windows 与浏览器渲染稳定。

## 桌面端与移动端要求

- 桌面端使用左侧个人摘要 + 右侧内容面板，适合快速扫描。
- 导航为单页切换，不拆成多个 HTML，也不把所有内容堆成长滚动页面。
- 移动端改为单列，导航横向滚动或换行显示。
- 图片使用固定比例或最大宽度，避免变形和溢出。
- 按钮在手机端占满宽度，便于触控。

## 关键文件职责

- `index.html`：页面骨架、导航按钮、侧栏和内容面板。
- `assets/css/style.css`：视觉系统、响应式布局、卡片和按钮样式。
- `assets/js/site-data.js`：可维护内容数据，包括能力、项目、证据和附件。
- `assets/js/main.js`：将数据渲染为网页卡片，并控制导航面板切换。
- `assets/files/`：PDF 下载材料。
- `assets/images/`：展示图和证明截图。

## 保留与修改

本项目没有使用大型开源模板，而是采用静态页面结构，以满足作业中“结构完整、真实内容、低复杂度、便于发布”的要求。

保留：

- 静态网站易发布、易核验的特点；
- 简历信息的完整顺序和可验证附件。

修改：

- 增加证明材料下载库；
- 增加创赛项目证书和材料截图展示；
- 删除单独排位证明下载，只保留两个正式奖状；
- 无相关图片的项目采用文字卡片，不硬配图；
- 将个人内容集中到数据文件，便于后续更新。

## 图片和外部素材来源

- 创赛证书、证明和商业计划书截图来自用户本人提供的 PDF 材料；
- 薪火集小程序截图来自用户本人提供的图片；
- 合成虚拟人气泡图来自用户本人提供的数据分析图片；
- 未使用未经授权的第三方图片。
