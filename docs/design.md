# 个人网站 Design

## 页面区块与浏览顺序

1. Hero：姓名、定位、下载简历、查看项目、国赛银奖关键成果。
2. About：金融科技学习背景与网站用途。
3. Skills：AI 产品、数据分析、商业调研、前端与 Vibe Coding。
4. Projects：狭路行者、薪火集、合成虚拟人用户、广货行天下。
5. Selected Evidence：创赛证书、项目书高含金量截图和个人排位证明。
6. Awards & Downloads：简历、证书、证明、项目节选和奖学金证明占位。
7. Contact：GitHub 与邮箱。

## 颜色、字体与整体风格

- 风格：明亮、专业、金融科技作品集，不使用黑色暗色背景。
- 主色：青绿色，用于按钮、强调信息和关键数字。
- 辅助色：陶土色和金色，用于标题辅助信息和荣誉感。
- 背景：米白、浅绿和白色，保持阅读轻盈。
- 字体：系统中文无衬线字体，优先保证 Windows 与浏览器渲染稳定。

## 桌面端与移动端要求

- 桌面端使用两栏 Hero 和图文项目卡，适合快速扫描。
- 移动端改为单列，导航自动换行。
- 图片使用固定比例或最大宽度，避免变形和溢出。
- 按钮在手机端占满宽度，便于触控。

## 关键文件职责

- `index.html`：页面骨架、导航、区块容器。
- `assets/css/style.css`：视觉系统、响应式布局、卡片和按钮样式。
- `assets/js/site-data.js`：可维护内容数据，包括能力、项目、证据和附件。
- `assets/js/main.js`：将数据渲染为网页卡片。
- `assets/files/`：PDF 下载材料。
- `assets/images/`：展示图和证明截图。

## 保留与修改

本项目没有使用大型开源模板，而是采用静态页面结构，以满足作业中“结构完整、真实内容、低复杂度、便于发布”的要求。

保留：

- 静态网站易发布、易核验的特点；
- Hero、About、Skills、Projects、Contact 基础结构。

修改：

- 增加证明材料下载库；
- 增加创赛项目证据截图展示；
- 将个人内容集中到数据文件，便于后续更新。

## 图片和外部素材来源

- 创赛证书、证明和商业计划书截图来自用户本人提供的 PDF 材料；
- 薪火集小程序截图来自用户本人提供的图片；
- 合成虚拟人气泡图来自用户本人提供的数据分析图片；
- 未使用未经授权的第三方图片。
