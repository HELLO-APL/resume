# 个人网站 PRD

## 目标访问者

主要访问者是 HR、课程教师、同学和潜在项目伙伴。他们最先需要找到：

- 陈怡凡是谁，基础信息和联系方式是什么；
- 是否具备金融科技、AI 产品、数据分析和商业表达能力；
- 代表项目和证明材料是否真实可核验；
- 如何联系或进一步查看材料。

## 希望访问者记住什么

陈怡凡是一名金融科技方向学生，能把 AI 产品理解、数据分析、商业调研和项目表达结合起来。重点记忆点是：

- 教育、实习、项目、比赛、科研经历完整可信；
- 中国国际大学生创新大赛 2025 国赛银奖项目经历；
- 在“狭路行者”项目中承担商业组组长、答辩人与 PPT 制作统筹职责；
- 因阶段表现突出，负责人在国赛阶段将个人排位提升至 2/15；
- 有 AI 审计实习、非遗小程序前端和合成虚拟人研究经历。

## 本期必须包含

- 单页导航切换：个人信息、教育背景、实习经历、项目经历、比赛经历、科研经历、技能荣誉、附件下载；
- 个人信息：首页展示姓名、学校学院、专业、GPA、均分、英语成绩、电话、邮箱、GitHub 和简历下载；
- 教育背景：课程、成绩、英文授课情况、培优奖学金；
- 实习经历：东亚银行 AI 审计产品经历；
- 项目经历：薪火集、广货行天下；
- 比赛经历：中国国际大学生创新大赛 2025，展示角色、贡献、奖项和部分项目材料截图；
- 科研经历：合成虚拟人用户项目，并展示相关气泡图；
- 附件下载：个人简历、国赛银奖证书、省赛银奖证书、狭路行者项目材料节选、奖学金证明占位；
- README、Design、Checklist、Final Report 和截图目录。

## 本期明确不做

- 不做登录、数据库、访客追踪、支付或复杂后台；
- 不引入复杂框架和无关依赖；
- 不公开密码、API Key、Token、课程邀请码或 `.env`；
- 不提交 55MB 的完整商业计划书原始 PDF，改用节选版和截图展示；
- 不展示单独排位证明 PDF，只保留两个正式奖状/证书；
- 没有相关图片的项目不硬塞无关图片；
- 奖学金证明在用户后续提供前只保留占位。

## 完成标准

- GitHub Pages 链接可访问；
- 简历顺序完整，且无模板占位文字；
- 导航切换可用，不依赖超长页面滚动查找信息；
- 桌面端和手机端布局清晰，无横向溢出、遮挡或不可读文字；
- 下载区材料链接有效，待补充材料明确标注；
- README、docs/prd.md、docs/design.md、docs/checklist.md、report/final-report.md 存在且与网站一致；
- screenshots/ 中保存桌面首页、手机首页、GitHub Pages 页面和 Checklist 证据截图；
- Git 至少有 3 次有意义提交。

## 不能公开的信息

- 密码、课程邀请码、API Key、Token、`.env`；
- 身份证件、住址、个人反馈页面；
- 未授权的大型原始材料；
- 用户后续未确认公开的奖学金证明。
