# 陈怡凡个人网站

这是陈怡凡的个人作品集网站，用于展示金融科技、AI 产品、数据分析、创新创业比赛经历，以及可公开下载的证明材料和个人简历。

## 模板与技术

本项目采用适合 GitHub Pages 的静态结构：

- `index.html`：页面结构
- `assets/css/style.css`：颜色、字体、间距和响应式样式
- `assets/js/site-data.js`：个人信息、项目、截图和下载附件数据
- `assets/js/main.js`：根据数据生成项目卡片、能力卡片和下载卡片
- `assets/files/`：可公开下载的 PDF 附件
- `assets/images/`：网页展示图片

项目保持低依赖、易发布、易维护，重点服务作业要求中的真实内容、规范过程、验证证据和 GitHub Pages 发布。
