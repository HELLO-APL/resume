# 陈怡凡个人网站

这是陈怡凡的个人简历网站，用于面向 HR 展示基本信息、教育背景、实习经历、项目经历、比赛经历、科研经历、技能荣誉，以及可公开下载的证明材料和个人简历。

## 模板与技术

本项目采用适合 GitHub Pages 的静态结构：

- `index.html`：页面结构
- `assets/css/style.css`：颜色、字体、间距和响应式样式
- `assets/js/site-data.js`：项目、比赛截图和下载附件数据
- `assets/js/main.js`：根据数据生成项目卡片、比赛截图、下载卡片，并控制导航切换
- `assets/files/`：可公开下载的 PDF 附件
- `assets/images/`：网页展示图片

项目保持低依赖、易发布、易维护，重点服务作业要求中的真实内容、规范过程、验证证据和 GitHub Pages 发布。

## 主要修改内容

- 按简历顺序组织为个人信息、教育背景、实习经历、项目经历、比赛经历、科研经历、技能荣誉和附件下载。
- 使用单页导航切换面板，避免把所有内容堆成长滚动页面。
- 联系方式放在首页侧栏，包含电话、邮箱和 GitHub 仓库。
- 完整呈现简历中的主要经历；没有相关图片的经历不硬配图。
- 比赛证明只保留国赛银奖证书和广东省赛银奖证书。
- 选择并压缩部分商业计划书截图，并提供项目材料节选 PDF，避免提交超大原始文件。
- 预留奖学金证明下载卡，等待后续补充。
