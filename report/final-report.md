# 最终报告：陈怡凡个人网站

## 1. 项目定位

本项目是陈怡凡的个人作品集网站，目标访问者包括 HR、课程教师、同学和潜在项目伙伴。网站重点展示金融科技学习背景、AI 产品与数据分析能力、创新创业比赛经历，以及可公开下载的证明材料。

## 2. 模板与技术选择

本项目采用纯静态网站结构，适合 GitHub Pages 发布。没有使用登录、数据库、复杂框架或无关依赖，原因是本次作业的重点是内容真实、过程规范、证据完整和可访问发布。

主要文件包括：

- `index.html`：页面结构；
- `assets/css/style.css`：视觉样式；
- `assets/js/site-data.js`：可维护内容数据；
- `assets/js/main.js`：内容渲染；
- `assets/files/`：证明材料和简历；
- `assets/images/`：项目截图和证书展示图。

## 4. AI 参与与个人判断

AI 协助完成了作业要求梳理、材料抽取、页面结构建议、静态网站实现、附件整理和文档初稿。个人判断主要体现在：

- 确认网站面向 HR 和课程验收；
- 确认可公开下载个人简历；
- 要求突出创赛中个人表现和排位提升，但避免生硬表述；
- 确认视觉风格为明亮、专业、非暗色；
- 决定使用部分高含金量截图展示商业计划书，而不是提交超大原始文件。
