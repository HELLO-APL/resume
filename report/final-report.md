# 最终报告：陈怡凡个人网站

## 1. 项目定位

本项目是陈怡凡的个人简历网站，目标访问者以 HR 为主，同时兼顾课程教师和项目伙伴。网站重点是按照简历顺序完整展示个人信息、教育背景、实习经历、项目经历、比赛经历、科研经历、技能荣誉和可公开下载的证明材料。

## 2. 模板与技术选择

本项目采用纯静态网站结构，适合 GitHub Pages 发布。页面为单个 HTML，但通过导航按钮切换内容面板，避免做成长滚动页面。没有使用登录、数据库、复杂框架或无关依赖，原因是本次作业的重点是内容真实、过程规范、证据完整和可访问发布。

主要文件包括：

- `index.html`：页面结构；
- `assets/css/style.css`：视觉样式；
- `assets/js/site-data.js`：可维护内容数据；
- `assets/js/main.js`：内容渲染；
- `assets/files/`：证明材料和简历；
- `assets/images/`：项目截图和证书展示图。

## 3. 主要修改

- 按简历顺序重构为个人信息、教育背景、实习经历、项目经历、比赛经历、科研经历、技能荣誉和附件下载。
- 联系方式放在首页侧栏，包含电话、邮箱和 GitHub。
- 项目经历完整呈现薪火集和广货行天下；没有相关图片的项目不硬配图。
- 比赛经历完整呈现“狭路行者”的角色、贡献、奖项和部分材料截图，但不让单个项目压过整份简历。
- 证明材料只保留国赛银奖证书和广东省赛银奖证书，不展示单独排位证明 PDF。
- 从商业计划书中选择市场、商业模式、财务预测等截图进行展示，并生成轻量节选 PDF。
- 奖学金证明尚未提供，网站中保留待补充卡片。

## 4. AI 参与与个人判断

AI 协助完成了作业要求梳理、材料抽取、页面结构建议、静态网站实现、附件整理和文档初稿。个人判断主要体现在：

- 确认网站面向 HR 和课程验收；
- 确认网站应像正式网页版简历，按简历顺序组织；
- 确认使用单页导航切换，而不是多个 HTML 或超长滚动页面；
- 确认可公开下载个人简历；
- 要求突出创赛中个人表现和排位提升，但避免生硬表述；
- 确认视觉风格为明亮、专业、非暗色；
- 决定只放两个正式奖状作为证明材料；
- 决定使用部分截图展示商业计划书，并提供节选附件，而不是提交超大原始文件。
